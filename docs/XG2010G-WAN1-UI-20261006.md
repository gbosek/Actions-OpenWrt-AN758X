# XG2010G WAN1 与管理界面修复

保留 R68 PON、1456.62 NPU、bridger/TC-BPF，以及启动 powersave、默认最大 1.4 GHz 的 CPU 修复。1.6 GHz 仍是未实机验证的可选上限。

## 动态硬件 WAN1

启动服务 S19hw-uplink 早于 network，按名为 wan 的防火墙区域、显式设置 hw_uplink=1 的区域或网络接口选择外部 GDM3/GDM4 物理口，通过驱动 933 的 hw-uplink 开关绑定 WAN1。仅有 masquerade 不作为 WAN 依据，避免把访客网络误选为 WAN。PON 保持 WAN0。

只有一个符合条件的外部 WAN 时自动选择；多候选时须在选中的网络接口设置 `option hw_uplink '1'`，其他接口可用 `option hw_uplink '0'` 排除。当前驱动只有一个外部硬件 WAN1 槽，不能据此声称三 WAN 全部支持卸载。

网络启动、更新、关闭，以及 network/firewall 的 UCI reload 后会重新核对。支持 @接口别名及具名 8021q/8021ad 设备；启动时同时检查 UCI 桥成员配置，避免桥尚未创建时误选 LAN。

已有绑定不重复切换；运行时角色变化需要短暂关闭端口及使用它的活动接口，随后尝试恢复。配置读取失败时保留现有角色；多个候选没有显式选择时保留有效 WAN 绑定，并释放已变为 LAN 的旧绑定。原 WorkBuddy 固定 wanb/lan3 的脚本不直接内置。

依赖 util-linux 的 flock 包进行有界等待，避免旧 mkdir 锁留下后阻止后续处理。同一配置下的失败尝试设置 30 秒冷却，抑制 ifdown/ifup 热插拔事件造成的重复中断。恢复失败仍会记录错误，需要实机检查。

939 补丁为动态 WAN1 设置 REG_WAN_MTU0 中的 WAN_MTU1_MASK，沿用上游 VLAN_ETH_HLEN 开销，并保留原 WAN0 路径。旧代码仅按逻辑 LAN/WAN 角色更新 WAN0，动态 WAN1 路径遗漏该字段。补丁已通过固定上游上下文检查、完整内核补丁栈应用和本地编译，尚未实机验证；不能据此归因以前的丢包。

验证需同时查看 hw-uplink、PPE 配置、对应实际流的 HW_OFFLOAD、双向 BND 和连续计数增长。PSE6/NBQ5/6 是 NPU 统计路径，不能单独代表物理出口。

### GDM2 出口修复已合并

938 回移 Linux 上游提交 8e0a754b0836d996802713bbebc87bc1cc17925c：存在真实 GDM2 端口时，其他 GDM 的 FOE 出口直接选目标端口。XG2010G 的设备树把 GDM2 用作 PON 数据路径；LAN3 位于 GDM4/NBQ1。933 的动态 WAN1 保留原直接路径，仅绑定硬件槽并清理旧流，不启用 GDM2 回环或切换整个 GDM 的 QDMA 角色。因此 PON 保持 GDM2，LAN3 WAN1 从 GDM4 输出。

938 与 939 已同时应用并编译进 20261006-0854 本地固件。tests/gdm2-egress-review.py 从实际准备的内核源码提取出口条件与枚举，用 C 夹具验证 GDM2 存在时 GDM3/GDM4 走直接出口，保留必要的旧平台回环后备，并检查 WAN1 不改逻辑 WAN 标志。GDM4 的原始 PSE 出口编号为 9；经过 NPU 统计改写后的可见编号不能直接拿来判定是否回环。

上游修复针对错误出口选择及硬件卸载问题。错误回环可能引入额外转发及共享队列压力；吞吐下降、延迟或丢包的具体程度尚未实机测量。实际 WAN 带宽饱和、PHY 错包和 PON 自身问题仍需分别检查。

## 系统菜单与 PON 卡片

新增挂载点、磁盘管理、文件管理、定时重启、Argon 设置；保留现有系统、管理权、软件包、启动项、计划任务、备份升级、重启和终端。

PON 卡片由仓库本地 luci-app-pon-status 提供，排序 15（系统 10 后），显示收发光功率、光模块温度、偏置电流、电压。缺少旧 pon.xpon 配置时仍尝试 pon0；空白、布尔值和无效数字不再显示为零。端口统计来源分别缓存，读取失败后允许重新探测；重复或无效设备配置会过滤。保留端口速率与连接数，连接数为整机统计。移除系统卡片已不用的 PON 查询。

## CPU 使用率

从 /proc/stat 两次采样计算整机平均使用率，浮点运算保留一位小数。修复整数除法导致低负载显示零的问题；计算包含 steal，不重复计算 guest。无有效采样显示 ?，不伪造零。该修复不证明每核负载均衡，也不改变 CPU 调频。
