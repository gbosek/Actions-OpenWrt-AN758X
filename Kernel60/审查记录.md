# XG2010G 6.18.60 升级审查

基线已在线复核：gbosek/Actions-OpenWrt-AN758X 最新成功构建 40740596825，提交 723fd37。本次沿用 NAOKI 单变体，在隔离分支 work/xg2010g-kernel-6.18.60-20261031 迁移；构建实际状态以 build-state.json 为准。

## 已处理的重复与兼容差异

1. 6.18.56 的 flowtable 待处理工作/回收同步、nft_flow_offload 初始化失败引用释放，以及 6.18.57 的 VLAN 去标签计数下溢，6.18.60 已原生包含，不重复叠加补丁。旧本地的 flowtable 销毁工作保护由稳定版完整实现接替；核对了 NF_FLOW_PENDING、GC 跳过待处理工作和工作结束前屏障。
2. PCS 606 中的索引上界检查已由 604 提供，删除重复的一个 hunk，保留四处端口数量赋值。
3. ARP 地址快照、IPv6 payload 长度、fq_codel MTU/quantum 等稳定版变更保留；旧补丁上下文重新适配。原队列若干 PHY/PCS/PON/GDM/MTU/BQL 补丁此前在 CI 就使用 fuzz，本次将最终结果写成精确上下文并重新零模糊度验证。
4. 新的完整路径错误传播同时适配了本固件自定义桥路径调用者，避免只改上游普通路由调用者而遗漏桥路径。VLAN 只取 VID，不把 PCP/DEI 当 VLAN ID；嵌套桥重置端口 VLAN 范围。
5. LEDE 的 FullCone 包路径与 PonWrt 不同，已改为本基线的 package/network/utils/fullconenat-nft；保留 010 的 6.12+ API 兼容。已核对原 nftables/libnftnl 属性编号与新内核模块一致。
6. 内核版本、模块路径、ABI、FIT 内核识别、成品检查脚本均改为精确 6.18.60。旧 6.18.54/55 安装器仍是构建的前置阶段，最终在 diy-part2 末尾升级，不能把前置文件里的历史版本号误认为交付内核。
7. 工具链缓存键纳入补丁文件，防止新增 musl 安全补丁却误用旧工具链。
