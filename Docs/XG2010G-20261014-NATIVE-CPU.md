# Use the repository CPU usage helper

The overview now calls /sbin/cpuusage and displays its original USR/SYS and CPU0–CPU3 string. The helper is copied unchanged from the repository main branch at 7a7c72e8a138c4dfe4f43d1801a408f45036069a. CPU-USAGE-SOURCE.json records this source. The previous custom ucode counter sampler and per-core renderer are removed from integration.

The temperature overlay path fix, MWAN4, PPE v2 and naoki Airoha 323539c remain included. Airoha source and version are unchanged. No CPU overclock patches are included in this change.

The release tag ends in nativecpu to distinguish this image from the still-running temperature-only build and keep the two releases from overwriting one another.
