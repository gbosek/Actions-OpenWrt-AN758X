# XG2010G EIP93 crypto integration

Select the existing Airoha EIP93 driver, cryptodev, OpenSSL utility and dynamic
devcrypto engine. Preserve the pinned Linux 6.18.55/PonWrt baseline, NPU1456,
guarded BND fixes and all board/PHY/DHCP/MWAN4 settings. No extra crypto driver
patch or forced algorithm/IRQ/clock tuning is introduced.

`EIP93-SOURCE.json` pins the stock package inputs and prepared EIP93 sources.
The EIP93 five source objects plus combined object and cryptodev combined object
passed local AArch64 `-Werror` compilation. Stock cryptodev 1.14 patches for
Linux 6.11 and 6.18 apply without fuzz. This is object compilation, not final
module linking or hardware verification.

The normalized OpenWrt Kconfig keeps all four packages selected and uses a
dynamic OpenSSL engine. The original `devcrypto.cnf` is preserved, including
`DIGESTS = NONE`; no global digest-engine activation is added.

Build checks require actual AArch64 driver modules, OpenSSL binary and engine,
autoload entries, exact package/kernel ABI and original crypto configuration.
`EIP93-BUILD-VERIFICATION.json` records staged file hashes. Offline ITB verification
checks the same files again in actual SquashFS.

`EIP93-OFFLINE-PACKAGES.tar.gz` retains the built crypto APK dependency closure.
It deliberately excludes kernel, libc and libopenssl3 replacements. The exporter
inspects actual APK metadata and rejects kernel dependencies differing from the
image; it never relabels a kernel dependency. Runtime installation still needs a
second comparison with the running device ABI and an offline transaction
simulation. Matching Linux version numbers alone are insufficient.

The inspected running image has ABI `44dc18a62cce2ae31a7f764626f31213`;
the public snapshot at inspection has `bf4d2f7b24371714b76437e4b40ae128`.
No mismatched module was installed or force-loaded. The router package database,
module list and SSL configuration were backed up before the package checks.
Installation remains pending an exact matching package; no reboot or flash was
performed. EIP93 crypto is independent of PPE BND counts.
